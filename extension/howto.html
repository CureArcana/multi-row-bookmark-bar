使い方How to use

Multi-Row Bookmark Bar は、Chrome のブックマークバーを複数段に拡張します。バーに入り切らないブックマークも、すべてページ上部に表示できます。

基本操作

  • バー右端の ⚙ — 設定パネルを開く（このページの「設定」と同じ内容をその場で変更できます）
  • バー右端の 🔍 — ブックマークを検索
  • 右クリック — 名前の変更・URL編集・削除・並べ替え・フォルダ作成など
  • Alt+Shift+B — バーの表示/非表示を切り替え

バーモード

  • 隠れた分のみ — Chrome標準バーに入り切らないブックマークだけを、続きとして表示します。
  • すべてのブックマーク — 全ブックマークを拡張バーに表示します。Ctrl+Shift+B で標準バーを非表示にすると、すべての操作が拡張バー内で完結するのでおすすめです。

表示方法

  • 自動非表示 — 普段は隠れ、マウスを画面上端に近づけると表示されます。アドレスバーや Chrome 標準ブックマークバーなど、ページより上のブラウザ UI にカーソルがある間も表示されます。ページのレイアウトに影響しません。
  • ページを押し下げ — 常に表示し、ページを下にずらします。

ドラッグ&ドロップ

✓ できること

  • 拡張バー内での並べ替え
  • アイテムをフォルダの中央にドロップしてフォルダへ移動
  • ページ上のリンクをバーへドラッグしてブックマークに追加
  • 拡張バーから Chrome標準バーへの移動（ブックマーク・フォルダとも）

✗ できないこと

  • Chrome標準バーから拡張バーへのフォルダの移動
Chrome はセキュリティ上の理由から、フォルダのドラッグ情報をページ側に渡しません。そのため、どの拡張機能でもこの操作は実装できません（URLブックマークは移動できます）。
回避策: バーモードを「すべてのブックマーク」にするか、ブックマークマネージャ（chrome://bookmarks）で移動してください。

ブックマークのショートカットキー

バー上のブックマークを右クリック →「ショートカットキーを割り当て」で、キー一発で新しいタブに開けるようになります（例: Alt+1 で YouTube）。スロットは9個あり、もう一度同じスロットを選ぶと解除できます。

Chrome の仕様で、初期キーを持てるのは拡張全体で4個までのため、Alt+1〜3 だけ最初から使えます。スロット4〜9を使うには Chrome のショートカット設定（chrome://extensions/shortcuts）でキーを割り当ててください。
同じ設定画面で各キーの右のプルダウンを「グローバル」に変えると、他のアプリがアクティブな時でもショートカットが効きます（Chrome 起動中のみ。そのキーは他のアプリでは使えなくなる点に注意）。

新しいタブ

  • カスタム — 新しいタブにも拡張バーを表示します。
  • Chrome標準 — 従来の新しいタブページを使います。
初めて新しいタブを開くと、Chrome が「新しいタブ ページが変更されました」という確認を表示します（Chrome の仕様で、どの拡張機能でも表示されます）。使い続けるには「変更を保持」を選んでください。「元に戻す」を選ぶと拡張機能が無効になります。

うまく表示されないとき

  • chrome:// ページや Chrome ウェブストアなど、拡張機能が動作できないページではバーは表示されません。
  • 「隠れた分のみ」モードで開始位置がずれる場合は、設定の「境界調整」で補正できます。

Multi-Row Bookmark Bar extends Chrome's bookmark bar to multiple rows, so every bookmark stays visible at the top of the page.

Basics

  • ⚙ at the right end of the bar — open the settings panel (same options as the Settings page here)
  • 🔍 at the right end — search bookmarks
  • Right-click — rename, edit URL, delete, sort, create folders, and more
  • Alt+Shift+B — toggle the bar

Bar mode

  • Overflow only — shows only the bookmarks that don't fit in Chrome's native bar, as a continuation.
  • All bookmarks — renders everything in the extension bar. Hide the native bar with Ctrl+Shift+B and everything lives in one place — recommended.

Display

  • Auto-hide — hidden by default; move the cursor to the top edge to reveal. The bar also stays visible while the cursor is over the browser UI above the page (address bar, native bookmark bar). Never alters page layout.
  • Push page down — always visible, shifting the page down.

Drag & drop

✓ Supported

  • Reordering within the extension bar
  • Dropping an item onto the middle of a folder to move it inside
  • Dragging links from a page onto the bar to bookmark them
  • Moving items from the extension bar to Chrome's native bar (bookmarks and folders)

✗ Not supported

  • Moving a folder from Chrome's native bar into the extension bar
For security reasons Chrome does not expose folder drag data to web pages, so no extension can implement this (URL bookmarks work fine).
Workaround: switch the bar mode to "All bookmarks", or move folders in the Bookmark Manager (chrome://bookmarks).

Bookmark shortcut keys

Right-click a bookmark on the bar → "Assign shortcut key" to open it in a new tab with a single keystroke (e.g. Alt+1 for YouTube). There are 9 slots; selecting the same slot again removes the assignment.

Chrome allows at most 4 default keys per extension, so only Alt+1–3 work out of the box. To use slots 4–9, assign keys in Chrome's shortcut settings (chrome://extensions/shortcuts).
On the same page, switching a key's dropdown to "Global" makes it work even while another app is active (Chrome must be running; note the key is then captured from other apps).

New tab

  • Custom — shows the extension bar on new tabs too.
  • Chrome default — keeps the standard new tab page.
The first time you open a new tab, Chrome asks whether to keep the change (this is Chrome's own prompt, shown for any extension). Choose "Keep it" to continue — "Restore settings" disables the extension.

Troubleshooting

  • The bar cannot appear on pages where extensions are not allowed to run, such as chrome:// pages and the Chrome Web Store.
  • If the starting position drifts in Overflow mode, correct it with "Boundary offset" in Settings.
