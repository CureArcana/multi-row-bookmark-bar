# Chrome ウェブストア掲載情報（ダッシュボードにコピペする用）

## ストア掲載情報タブ

**名前**: Multi-Row Bookmark Bar

**概要（132文字以内）**:
```
ブックマークバーに入り切らないブックマークを2段目以降に自動表示。Chrome純正そっくりの見た目で、D&D・フォルダ・検索・多段折り返しに対応。ページのレイアウトは一切変更しません。
```

**詳細説明**:
```
Chromeのブックマークバーは1行しか表示できず、入り切らないブックマークは「>>」の中に隠れてしまいます。この拡張機能は、隠れた分を2段目以降として自動表示します。

【特徴】
■ 隠れた分だけを続きとして表示 — 標準バーの「>>」に入ったブックマークから自動で開始。全部収まっている時はバー自体が消えます
■ Chrome純正そっくりの見た目 — フォント・色・フォルダアイコン・ホバーを実測で一致。ダークモード対応
■ ページを一切変更しない — バーは普段隠れていて、カーソルを画面最上端に持っていくと表示（オートハイド）。どんなサイトでもレイアウトが崩れません。常時表示（押し下げ）モードも選択可
■ ドラッグ&ドロップ — 多段バー内の並べ替え、標準バーとの間の移動、フォルダへの投入に対応
■ フォルダ・検索・右クリックメニュー — ホバーでフォルダ展開（サブフォルダ対応）、ブックマーク検索、名前変更・削除・ソート
■ リアルタイム同期 — ブックマークの追加・削除・並べ替え、タブグループの増減に即時追従
■ 新しいタブページ（切替式）— 多段バー+Google検索ボックス付きのカスタムページ。設定でChrome標準にも戻せます
■ 日本語・英語対応 — ブラウザの言語に自動追従、設定で固定も可能

【プライバシー】
外部サーバーとの通信は一切ありません。ファビコンもブラウザ内蔵キャッシュを使用します。データ収集・解析・広告なし。

ソースコードはGitHubで公開しています:
https://github.com/CureArcana/multi-row-bookmark-bar
```

## プライバシーへの取り組みタブ

**単一用途の説明**:
```
ブックマークバーに入り切らないブックマークを、バーの続きとして2段目以降に多段表示する。
```

**権限の使用理由**:

| 権限 | 理由（コピペ用） |
|------|------|
| bookmarks | バーに表示するブックマークの読み取りと、バー上での操作（並べ替え・作成・名前変更・削除・ソート）のために使用します。 |
| storage | ユーザー設定（表示方式・行高さ・言語など）の保存と同期に使用します。 |
| favicon | ブックマークのファビコンをブラウザ内蔵キャッシュ（_favicon API）から表示するために使用します。外部サービスへの問い合わせは行いません。 |
| tabGroups | ブックマークバー左側に表示されるタブグループのチップの幅を計算し、標準バーに表示されているブックマーク数を正確に推定するために使用します（タイトル文字列の幅計測のみ）。 |
| ホストへのアクセス（コンテンツスクリプト <all_urls>） | すべてのWebページの上部に多段ブックマークバーを描画するために必要です。ページの内容は読み取らず、データの収集・送信も行いません。 |
| chrome_url_overrides (newtab) | 新しいタブに多段バー付きのカスタムページを提供します。設定でChrome標準の新しいタブに戻すことができます。 |

**リモートコード**: 使用していません
