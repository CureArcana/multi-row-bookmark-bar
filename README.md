# Multi-Row Bookmark Bar

Chromeのブックマークバーに収まりきらない（`>>` に隠れている）ブックマークを、バーの続きとして2段目以降に表示するChrome拡張機能です。

```
┌──────────────────────────────────────────────────┐
│ Google  GitHub  Twitter  YouTube  Reddit  ... >> │ ← Chrome標準バー（そのまま）
├──────────────────────────────────────────────────┤
│ Notion  Discord  Figma  Qiita  Zenn  ...         │ ← 隠れていた分をここから表示
├──────────────────────────────────────────────────┤
│ Holodex  Qiita  Zenn                             │ ← 3段目以降も自動
└──────────────────────────────────────────────────┘
```

## Features

- **オーバーフロー連続表示** — 標準バーの1行に入り切らず隠れたブックマークから動的に開始（全部入る時はバー自体が消える）
- **ネイティブバーの状態に自動追従** — タブグループの増減は即時再計算。Ctrl+Shift+B で標準バーを消すと自動で全ブックマーク描画（推定不要で常に完全一致）に切替、F11 全画面ではバーを出さない
- **Chrome純正と同一の見た目** — フォント・背景色・文字色・フォルダアイコン・ホバーはChrome実測値に合わせて完全一致（ダークモード対応）
- **ページを一切変更しない（オートハイド・デフォルト）** — バーは普段画面外に隠れていて、カーソルを画面最上端に持っていくと降りてくる。ページのレイアウトに全く触れないため、どんなサイトでも崩れない
- **押し下げモード（オプション）** — 常時表示したい場合は Display 設定で「ページを押し下げて常時表示」を選択（fixed/stickyヘッダーの自動オフセット付き。サイトによっては崩れる場合あり）
- **自動折り返し** — ウィンドウ幅・ブックマーク増減に応じて段数が自動で変わる
- **フォルダ対応** — ホバーでドロップダウン展開（サブフォルダも再帰対応）
- **ドラッグ&ドロップ** — 多段バー内での並び替え・フォルダへの投入（実際のブックマーク位置に反映）
- **リアルタイム同期** — ブックマークの追加・削除・移動を即座に反映
- **検索・ソート・右クリックメニュー** — バー上で完結
- **Alt+Shift+B** — バーの表示/非表示をトグル
- **新しいタブページ（切替式）** — 多段バー+Google検索ボックス付きのカスタムページに差し替え可能（設定でChrome標準にも戻せる）

## Install

Chrome Web Store経由ではなく、GitHubから直接インストールします。**Googleの審査は不要**です。

1. このリポジトリの `multi-row-bookmark-bar-v1.6.0/` フォルダを入手（クローン or ZIPダウンロード）
2. Chromeで `chrome://extensions` を開く
3. 右上の **「デベロッパーモード」** をONにする
4. **「パッケージ化されていない拡張機能を読み込む」** → `multi-row-bookmark-bar-v1.6.0/` を選択

ビルドは不要です（プレーンJS構成）。

## Settings

拡張アイコンのポップアップ、またはバー左端のギアから設定できます。

| 設定 | デフォルト | 説明 |
|------|-----------|------|
| 有効/無効 | ON | 拡張の一時無効化（Alt+Shift+Bでも切替） |
| Bar mode | Overflow only | 隠れた分だけ表示 / 全ブックマーク表示(v1.5.1方式) |
| 最大段数 | 0（無制限） | 表示する最大段数 |
| アイテム表示 | アイコン+テキスト | アイコンのみ / テキストのみも選択可 |
| フォルダ展開 | ホバー | クリック展開にも変更可 |
| 表示条件 | 常に表示 | 新しいタブのみに制限可 |
| フォントサイズ / 行高さ | 12px / 36px | 拡張バー側の見た目調整 |

## Development / Test

```bash
npm install

# E2Eテスト（Chrome for Testing に拡張を読み込んで全機能を検証）
npm run test:e2e

# ネイティブバーとの見た目比較（ヘッドフルでウィンドウが一瞬表示されます）
npm run test:visual
```

> 製品版Chrome 137以降は `--load-extension` が無効化されているため、
> 自動テストは puppeteer が導入する Chrome for Testing 上で実行されます。

## How it works

- ネイティブバーが何個表示できるかは、Chrome実測から逆算した寸法モデル
  （アイテム幅 = テキスト幅 + 40px、左右予約55px）とCanvasテキスト計測で推定します
- 拡張バーはShadow DOMで描画され、ページCSSの影響を受けません
- ページは `body` の `margin-top` と fixed/sticky 要素の `top` オフセットで押し下げます

## Known Limitations

- `chrome://` ページやChromeウェブストアでは動作しません（Chromeのセキュリティ制限）。新しいタブはカスタムNTP（デフォルト有効）で対応できます
- ネイティブバーの収容数は推定のため、フォント設定やChromeのUI変更によって±1個ズレる可能性があります（その場合は `test/calibrate.mjs` で再キャリブレーション）
- ブックマークバー非表示設定（Ctrl+Shift+B でOFF）の場合は Bar mode を「All bookmarks」にしてください
